# ccs-chademo
CCS to CHAdeMO adapter information and code  

This repository serves as a centre for gathering together both the code and all the relevant 
information (ccs-chademo/wiki) necessary to build a CCS2 to CHAdeMO adapter interfacing    
a UK CCS2 charger to a Nissan Leaf model 2 (Tekna+ with a 62kWh battery).  

It draws (almost) entirely on information from the https://openinverter.org/forum/index.php forum,  
and in particular topic https://openinverter.org/forum/viewtopic.php?p=85930&hilit=osexpert#p85930   

The work of Uwe Hennig (https://github.com/uhi22), Johannes Huber (https://github.com/johu), and many  
more is gratefully acknowledged.  This repo simply serves to pull together, for my own use,  all the  
information and a limited subset of the Python code for the specific purpose stated.

In addition, the considerable work done more recently (https://github.com/osexpert/ccs32clara-chademo) 
on the STM32 with QCA7005 as a CCS charge controller (see uhi22/ccs32clara etc) has added a lot of  
useful practical investigative work on the Nissan (and other) CHAdeMO implementations, and this is  
gratefully acknowledged.
